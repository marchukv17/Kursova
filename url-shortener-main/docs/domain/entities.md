# LinkForge — сутності домену

Домен поділено на bounded contexts (див. `context_map.png`). Нижче — ключові
сутності кожного контексту, їхні атрибути та мінімальна поведінка, яку вони
інкапсулюють. Атрибути відповідають коду в `src/domain/`.

## Контекст Links (ядро)

Це серце продукту: `Link`, що зіставляє `Slug` з `OriginalUrl`.

### Link (корінь агрегату)

| Атрибут       | Тип             | Примітки                                             |
|---------------|-----------------|------------------------------------------------------|
| `id`          | string (uuid)   | Ідентичність агрегату, призначається при створенні.  |
| `slug`        | string          | Унікальний, URL-безпечний, `^[A-Za-z0-9_-]{3,32}$`. Незмінний. |
| `originalUrl` | string (uri)    | Призначення; має бути абсолютним `http`/`https`.     |
| `title`       | string \| null  | Людський заголовок, необов'язковий.                  |
| `clicks`      | integer ≥ 0     | Лічильник, що зростає при кожному успішному розв'язанні. |
| `createdAt`   | datetime        | Встановлюється один раз при створенні (ISO-8601).    |
| `updatedAt`   | datetime        | Оновлюється при кожній зміні змінюваного поля.       |

**Інваріанти**

- `originalUrl` завжди є валідним абсолютним URL `http`/`https`.
- `slug` унікальний серед усіх посилань і ніколи не змінюється після створення.
- `clicks` монотонний (лише зростає).

**Поведінка (методи)**

- `Link.create(input)` — валідує й нормалізує `originalUrl`, `slug`, `title`.
- `Link.update(existing, patch)` — валідує змінювані поля, зберігає `slug`.
- `Link.fromRow(row)` — відновлює сутність із рядка бази даних.
- `toJSON()` — мапиться у DTO відповіді API.

**Похідне значення**

- `shortUrl` — `BASE_URL + "/" + slug`; обчислюється на межі API, не зберігається.

### Slug (value object)

`Slug` — це value object, а не окрема таблиця: він існує лише як частина `Link`.
Правила: 3–32 символи, `[A-Za-z0-9_-]`, глобально унікальний. Якщо користувач не
задав slug, система генерує випадковий 7-символьний slug і повторює при колізії.

### ClickCounter (value object)

Невід'ємне ціле, що живе на `Link`. Збільшується рівно один раз за кожне успішне
розв'язання `GET /{slug}`. Він навмисно простий — поки без журналу подій.

## Контекст Items (підтримувальний)

Свідомо крихітний контекст, що доводить конвеєр «клієнт → бекенд → база даних»
(лаб. 1). Не має жодного зв'язку з контекстом Links.

### Item

| Атрибут | Тип     | Примітки                        |
|---------|---------|---------------------------------|
| `id`    | integer | Автоінкрементний первинний ключ.|
| `name`  | string  | Відображувана назва; обов'язкова.|

**Поведінка:** лише читання списку (`list()`), мапінг рядок → `Item.toJSON()`.

## Контекст Identity (загальний, майбутній)

Ще не реалізовано. Надаватиме контексту Links інформацію про власність через
anti-corruption layer.

### User (заплановано)

| Атрибут | Тип    | Примітки                          |
|---------|--------|-----------------------------------|
| `id`    | string | Ідентичність акаунта.             |
| `email` | string | Логін (унікальний).               |
| `role`  | enum   | `creator` \| `operator`.          |

## Контекст Analytics (майбутній)

Споживає події `LinkClicked`, які публікує контекст Links.

### ClickEvent (заплановано)

| Атрибут      | Тип      | Примітки                               |
|--------------|----------|----------------------------------------|
| `id`         | string   | Ідентифікатор події.                   |
| `linkId`     | string   | Посилання на `Link`.                   |
| `occurredAt` | datetime | Коли стався редірект.                  |
| `metadata`   | object   | Необов'язково: user-agent / referrer.  |

### Report (заплановано)

Агрегована модель читання: кліки на посилання за день. Контекст Links її ніколи не
записує; вона будується лише з `ClickEvent`.

---

## Зв'язки контекстів (підсумок)

- **Links → Analytics**: публікує `LinkClicked` (customer/supplier).
- **Identity → Links**: постачає `ownerId` через ACL (upstream/downstream).
- **Items**: незалежний; без залежності від Links чи Identity.
- **Notifications → Links**: реагує на події закінчення терміну дії (майбутнє).
